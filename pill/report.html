A tournament of image-cleanup and counting techniques, run as a branching pipeline. Each run is one path through the stages; every score is EXACT counts on hand-verified labels only. Techniques that lost are shown too — a negative result is a result.

Where the losses happen

Each failure is classified by comparing the blob count in the final mask to the true pill count. This says which stage to fix: merged too few blobs — a splitting problem. noise too many blobs — a mask problem. counting blob count is already right and we still miscount — pure post-mask logic.
